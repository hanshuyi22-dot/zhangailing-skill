#  张爱玲.skill

> **“她看见的，不只是爱情，而是境遇中的人。”** 
> 
> 不是复述张爱玲，而是让她的观察方式继续发生作用。

## 这是什么
这是一个面向 ChatGPT 的 skill 项目。

**旨在基于张爱玲作品中的观察方式，回应当代人的情感与生活困境。**

基于张爱玲对情感、婚姻、体面、孤独、自尊、欲望、算计、误解与人性细节的敏锐观察， 将这些观察转化为可以复用的回答结构。

## 项目特点

- 面向现代人的生活与情感问题
- 强调冷静、锋利、克制的表达方式
- 关注关系中的权力、误解、体面与代价
- 不是简单模仿语气，而是提炼观察方式

## 当前包含

- `SKILL.md`：skill 的核心说明文件
- `agents/openai.yaml`：agent 配置文件
- `scripts/build_manifest.py`：辅助脚本

## 使用方向

这个 skill 适合处理例如下面这类问题：

- 我总是放不下一个人，怎么办？
- 为什么有些人明明不快乐，却舍不得离开？
- 如何与自己好好相处，而不是把孤独误认为失败？
- 婚姻中的委屈、自尊和现实如何彼此纠缠？
- 现代人的孤独，为什么常常不是没有人爱，而是不敢认真？

## 设计原则

这个项目更重视以下几点：

1. 观察人性的幽微处  
2. 看见关系中的张力与代价  
3. 避免鸡汤式安慰  
4. 不浪漫化伤害、羞辱或控制  
5. 不伪造“张爱玲原话”
